# Search Summary Output Schema

This document describes `search/summary.yaml` generated by the analyze pipeline search exporter.

## Location

```text
outputs/<run_timestamp>/analyze/<SYMBOL>/search/summary.yaml
```

This file is produced when search queries are present and `search.export_results` is enabled.

## Top-level fields

- `symbol`
- `score_threshold`
- `metadata_filters`
- `total_queries`
- `total_unique_results`
- `queries` (list of per-query sections)
  - `query`
  - `results_count`
  - `stats`
    - `average_score`
    - `best_score`
    - `symbols`
    - `sections`
    - `tag_frequency`
    - `sentiment_breakdown`
  - `highlights`
    - `top_summaries`
  - `results` (per-hit payloads)
    - `score`
    - `content`
    - `metadata`
    - `summary`
    - `tags`
    - `sentiment`
    - `forward_looking`
    - `confidence_score`
- `unique_results` (cross-query de-duplicated hits)
  - `content`
  - `metadata`
  - `matched_queries` (`query`, `score`)
  - `best_score`

## Rounding conventions

- Search score values are rounded to 2 decimals.
- Numeric payload formatting is handled by shared serialization helpers.
