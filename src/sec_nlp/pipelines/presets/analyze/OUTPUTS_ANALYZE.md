# Analyze Output Schema

This document describes the `analysis.yaml` payload generated by the analyze pipeline.

## Primary location

```text
outputs/<run_timestamp>/analyze/<SYMBOL>/<accession>/analysis.yaml
```

`analysis.json` and `analysis.csv` are emitted when the selected export format includes them.

## Related analyze artifacts

- `outputs/<run_timestamp>/analyze/<SYMBOL>/analysis_summary.yaml`
- `outputs/<run_timestamp>/analyze/<SYMBOL>/search/summary.yaml` (when search export is enabled)
- `outputs/<run_timestamp>/analyze/peer_summary.yaml` (when run includes multiple symbols)

## Top-level fields in `analysis.yaml`

- `symbol`
- `search_queries`
- `filing`
  - `accession_number`
  - `form_type`
  - `acceptance_date`
  - `filing_date`
- `executive_summary`
  - `status`
  - `result_count`
  - `total_chunks`
  - `relevant_count`
  - `average_confidence`
  - `top_tags`
  - `top_topics`
  - `key_points`
- `executive_comp_summary` (present for proxy-oriented analyses when data exists)
  - `executives`
  - `compensation_items`
  - `performance_metrics`
  - `peer_set`
  - `pay_for_performance_flags`
  - `notes`
- `aggregates`
  - `tag_frequency`
  - `sentiment_breakdown`
  - `sections_covered`
  - `topic_hits_frequency`
  - `impact_channel_frequency`
  - `impact_horizon_frequency`
  - `impact_direction_frequency`
  - `impact_magnitude_frequency`
  - `binding_status_frequency`
  - `forward_looking_count`
- `diagnostics`
  - `chunks_analyzed`
  - `chunks_successful`
  - `chunks_failed`
  - `chunks_relevant`
  - `success_rate`
  - `relevant_rate`
  - `timings`
  - `confidence_threshold`
- `provenance`
  - `run_id`
  - `pipeline_version`
  - `model_name`
  - `confidence_mode`
  - `prompt_path`
  - `prompt_version`
  - `schema_version`
- `market_enrichment` (optional)
- `market_correlation` (optional)
- `results` (ranked relevant hits)
- `results_by_query`
- `results_by_section`
- `relationship_timeline`

## Rounding/serialization conventions

- Score-like metrics are rounded to 2 decimals.
- Timing values are rounded to 3 decimals.
- Output serialization is centralized through shared pipeline serialization helpers.
