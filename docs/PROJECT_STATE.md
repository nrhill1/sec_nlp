## Pipeline Inventory

| Pipeline | Default scope/mode | Default forms | Default output format | Notes |
| --- | --- | --- | --- | --- |
| `analyze` | `FilingMode.annual` | mode-derived unless overridden | `yaml` | Optional EFTS expansion, vector search, and market correlation |
| `exhibit` (`exb`) | `FilingMode.annual` | mode-derived unless overridden | `yaml` | Embedding/index pipeline for exhibit categories/numbers |
| `warranty` | `FilingMode.annual` (enforced) | annual (10-K) | `both` (JSON + CSV) | XBRL-first warranty period extraction |
| `financials` | base symbols/date range + `form_types` | `10-K`, `10-Q` | `csv` | Structured line items + optional ratio/delta report |
| `holdings` | `FilingMode.holdings` (enforced) | `13F-HR`, `13F-HR/A` | `csv` | 13F snapshot + QoQ diff |
| `insider` | `FilingMode.insider` (enforced) | `3`, `4`, `5` | `csv` | Transactions, ledgers, cluster/alert generation |
| `news` | `FilingMode.current` | `8-K`, `10-K`, `10-Q` | `json` | News timeline with optional market-correlation context |
| `events` | `FilingMode.current` (enforced) | `8-K`, `6-K` | `json` | Event detection + event-study scoring |
| `retrieve` | `FilingMode.annual` | `10-K`, `10-Q` | `json` | EFTS candidate ranking with stopword-aware lexical pruning, selective hydration, and optional embedding rerank/index |
| `chat` | `FilingMode.annual` | optional filter | `all` | Retrieval-augmented Q&A over indexed chunks |

## Output Layout (Current)

Global run root:

```text
outputs/<run_timestamp>/<pipeline_type>/<SYMBOL>/...
```

Analyze (per accession):

```text
outputs/<run_timestamp>/analyze/<SYMBOL>/<accession>/analysis.{yaml,json,csv}
outputs/<run_timestamp>/analyze/<SYMBOL>/analysis_summary.yaml
outputs/<run_timestamp>/analyze/<SYMBOL>/search/summary.yaml
outputs/<run_timestamp>/analyze/peer_summary.yaml   # when >1 symbol
```

Exhibit:

```text
outputs/<run_timestamp>/exhibit/<SYMBOL>/<symbol>_exhibit_index_<run_id>.{yaml,json,csv}
outputs/<run_timestamp>/exhibit/<SYMBOL>/<symbol>_exhibit_summary_<run_id>.{yaml,json}
outputs/search/<run_timestamp>/<query_slug>.yaml   # semantic search exports
```

Warranty:

```text
outputs/<run_timestamp>/warranty/<SYMBOL>/<symbol>_warranty_<accession>_<run_id>.json
outputs/<run_timestamp>/warranty/<SYMBOL>/<symbol>_warranty_combined_<run_id>.csv
```

Financials:

```text
outputs/<run_timestamp>/financials/<SYMBOL>/<symbol>_financials_<run_id>.{csv,json,yaml}
```

Holdings:

```text
outputs/<run_timestamp>/holdings/<SYMBOL>/<symbol>_holdings_<run_id>_snapshot.csv
outputs/<run_timestamp>/holdings/<SYMBOL>/<symbol>_holdings_<run_id>_summary.{json,yaml}
outputs/<run_timestamp>/holdings/<SYMBOL>/<symbol>_holdings_<run_id>_diff.{json,yaml}
```

Insider:


News / Events / Retrieve / Chat:

## Extension Dependencies

- EFTS Rust extension (`efts`) is required by `sec-nlp efts` and retrieval paths that call the EFTS client.
- Market Rust extension (`market`) powers `sec-nlp market` and any market-context/correlation features.
- Qdrant is optional but required for vector-backed retrieval/search workflows.

## Run Registry

- SQLite DB: `.cache/sec-nlp/runs.db`
- Tracks run IDs, short IDs, status, timing, output dir, and metadata.
- Managed with `sec-nlp runs` subcommands.
